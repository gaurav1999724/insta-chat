# Build a Complete Instagram AI Chat Assistant

You are a senior full-stack engineer, AI engineer, UI/UX engineer, and software architect.

Build a complete production-quality web application called:

InstaMate AI

The application is a personal AI assistant for helping the authenticated user manage Instagram conversations using Meta's official Instagram APIs.

The core idea is:

The user connects their Instagram account, selects an eligible conversation, chooses how they want the AI to communicate, and the AI generates natural Hinglish responses using Google Gemini.

Example modes:
- Casual
- Friendly
- GF / Romantic
- Flirty
- Study
- Business
- Professional
- Funny
- Supportive
- Custom

The AI should communicate naturally in Hinglish rather than sounding like a robotic chatbot.

The user must always be able to disable AI and manually take over the conversation.

IMPORTANT:
Use only Meta's official Instagram APIs and officially supported messaging capabilities.

DO NOT use:
- Selenium
- Playwright for Instagram automation
- Browser scraping
- Instagram password automation
- Reverse-engineered Instagram APIs
- Private Instagram endpoints
- Unofficial Instagram libraries
- Session/cookie hijacking
- Automated login to Instagram
- Any method intended to bypass Meta restrictions

If a requested Instagram capability is not supported by Meta's official API, do not implement an unofficial workaround. Clearly document the limitation and design the application around the supported flow.

# 12. IMPORTANT — CHAT STYLE

The AI should NOT sound like a robotic AI assistant.

Default communication style:
- Natural Hinglish
- Conversational
- Short messages
- Context-aware
- Informal when appropriate
- Avoid unnecessary explanations
- Avoid corporate language unless Business mode is selected
- Avoid repeatedly saying "Sure", "Absolutely", "I understand"
- Avoid automatically using bullet points in normal conversations
- Do not overuse emojis
- Match the other person's communication style
- Match approximate message length
- Understand Hindi written in Roman script
- Understand English
- Understand Hinglish
- Respond primarily in Roman-script Hinglish

Example:

Person:
"kal kya plan hai?"

Bad:
"Hello! Kal ke liye mera koi specific plan nahi hai. Aap bataiye aap kya karna chahte hain?"

Good:
"abhi toh kuch fixed nahi hai 😅 tumhara kya plan hai?"

# 13. HINGLISH ENGINE

Create a dedicated AI instruction layer.

Default language:
HINGLISH_ROMAN

Rules:
1. Hindi should normally be written using English/Roman script.
2. English words are allowed naturally.
3. Do not randomly switch to Devanagari.
4. Do not translate every English word into Hindi.
5. Use natural Indian conversational phrasing.
6. Match the person's language.
7. If the other person uses mostly English, use more English.
8. If the other person uses Hinglish, use Hinglish.
9. If the other person uses Hindi in Roman script, use Roman Hindi.
10. Avoid overly formal Hindi.
11. Avoid unnatural slang unless the conversation establishes it.

# 74. AUTHORIZATION

Every conversation must belong to an Instagram account belonging to the authenticated user.

Never allow:
User A → access User B's conversation.

Check ownership server-side on every protected operation.

Never rely only on frontend route protection.

# 75. AI MEMORY PRIVACY

Allow the user to:
- View memory
- Edit memory
- Delete memory
- Disable memory
- Clear conversation memory

The AI should only use memory relevant to the current conversation.

# 76. PERSONAL NOTES

Allow user-only private notes about a conversation.

These notes:
- must never be sent to the Instagram contact
- may be used by the AI if the user enables that behavior
- must remain private

# 77. CHAT MODE SWITCHING

The user should be able to change mode at any time.

Example:

Current:
FRIENDLY

Change to:
FLIRTY

Next AI response should use FLIRTY mode.

Do not rewrite old messages.

# 78. MODE PREVIEW

When selecting a mode, show:
- Name
- Description
- Example style
- Example generated message

Clearly label generated examples as AI-generated examples.

# 79. CUSTOM INSTRUCTIONS

Allow conversation-specific instructions.

Examples:
- "Keep replies very short."
- "Use more Hinglish."
- "Don't use emojis."
- "Talk casually."
- "Ask questions instead of giving long answers."

Validate and sanitize these instructions.

# 80. AI BEHAVIOR RULE

The AI should respond to the actual conversation rather than forcing the selected mode.

For example:

Mode = Flirty

Incoming:
"mere exam ka result aa gaya"

The AI should first respond appropriately to the result rather than unnecessarily flirting.

Context always has priority over stylistic decoration.

# 81. NATURAL CONVERSATION RULES

Implement prompt rules:
- Don't answer every message with a question.
- Don't always end with "tum batao".
- Don't overuse emojis.
- Don't repeat the same phrases.
- Don't use "haha" in every response.
- Don't over-explain.
- Don't sound scripted.
- Don't produce paragraphs for simple messages.
- Match the user's conversational energy.
- Remember relevant earlier information.
- Refer back to previous topics naturally.
- Avoid repetitive greetings.
- Avoid repetitive compliments.
- Avoid robotic acknowledgments.

# 82. HUMAN-LIKE STYLE WITHOUT FALSE CLAIMS

The goal is natural conversational language.

Do not fabricate:
- physical presence
- actions
- calls
- meetings
- experiences
- memories that do not exist
- knowledge that was not provided

If the AI doesn't know something, it should not invent it.
